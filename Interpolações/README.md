# Interpolações
Link do projeto no itch.io : https://nefrosada.itch.io/interpolacoes

No projeto existe um menu interativo para mudar opções das interpolações durante a execução, podendo criar novos pontos, mudar a posição deles, até podendo simular a animação do personagem percorrendo por esses pontos, podendo mudar o tempo no qual o objeto anda e o tipo de interpolação a se fazer.

Atualmente no projeto existem 2 tipos de interpolações integrados:

	1- Interpolação linear

	2- Curva de Bezier
