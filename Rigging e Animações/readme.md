# Rigging e Animações

Nesse trabalho foi necessário serem feitas diversas partes, o personagem foi criado utilizando o aplicativo Fuse, diponibilizado gratuitamente na Steam. 
Depois de feito foi colocado no site Mixamo para ser criado o rigging do personagem e ser implementadas as animações escolhidas. 
Todas as animações então foram postas no site: https://nilooy.github.io/character-animation-combiner/, em que mistura todas as animações feitas em apenas 1 modelo.
Esse modelo então foi colocado no motor Godot e lá com um script e os nodos do programa foram feitas uma simples cena onde dependendo do botão pressionado o personagem faz uma animação diferente.
O programa pode ser testado no seguinte site: https://nefrosada.itch.io/criao-rigging-e-animao
